# NFT Ticketing Platform

Event tickets as NFTs: mint, transfer with organizer controls, and
fraud-resistant redemption at the door — no duplicate entry, no
counterfeit tickets. Built with Foundry (Solidity 0.8.24).

## Roadmap

- [x] Project scaffold (Foundry, README, CI)
- [ ] Event + ticket contracts (mint, pricing, supply caps)
- [ ] Transfer controls (organizer allowlist, resale price cap)
- [ ] Redemption (single-use check-in, anti-replay)
- [ ] Tests + gas report, then self-review checklist, then public

## Quick start

```bash
forge build
forge test
```
